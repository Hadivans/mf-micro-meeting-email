# The Meeting That Should Have Been an Email

A make.fun one-liner entry: one funny line, at most 200 characters, about a
meeting that should have been an email.

> This meeting could have been an email, but then how would we spend an hour
> agreeing on nothing and booking a follow-up to do it all again?

`main.py` (stdlib only) writes that single line to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `output/`).
